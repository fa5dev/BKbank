# БК-Банк

Добро пожаловать в БК-Банк — ваш надёжный финансовый партнёр!

## 🌐 Демо

Сайт: https://fa5dev.github.io/BKbank/

## ✨ Возможности

- 🏠 Лендинг с анимациями и эффектами
- 💳 Эксклюзивные карты (7 видов) в интерактивной стопке
- 🔐 Регистрация и вход (данные в localStorage)
- 👤 Личный кабинет: имя, email, телефон, аватар
- 💰 Внутренняя валюта BK и баланс
- 👥 Друзья и запросы в друзья
- 💾 Бекап / восстановление аккаунта
- 📱 PWA — устанавливается как приложение

## 🛠 Технологии

- HTML5, CSS3 (glassmorphism, анимации)
- Vanilla JavaScript (без фреймворков)
- localStorage для хранения данных
- Service Worker + Web App Manifest (PWA)
- CryptoJS (для хеширования паролей)

## 🚀 Локальный запуск

Просто открой index.html в браузере.

## 📄 Лицензия

Учебный / демо-проект.
